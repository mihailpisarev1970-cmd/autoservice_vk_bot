# Changelog

Все значимые изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2025

### Добавлено
- VK-бот на `vkbottle` 3.0 с Long Poll API: главное меню из 6 разделов.
- Запись на ТО: интерактивный календарь на 8 дней, свободные слоты времени из CRM,
  пошаговый сбор данных (имя, автомобиль, причина обращения).
- ИИ-диагностика автомобиля: текст, фото (сжатие через Pillow), голосовое сообщение
  (транскрибация через Whisper-совместимый endpoint).
- Проверка статуса ремонта по последней записи клиента.
- Раздел «Адрес и контакты» с кнопками Яндекс Карт и 2ГИС, прайс-лист, связь с дежурным мастером.
- Клиент Baserow REST API: чтение занятых слотов, создание и поиск заявок.
- Dockerfile и `docker-compose.yml` для запуска в контейнере с автоперезапуском.
- Шаблон переменных окружения `.env.example`, `.gitignore`, `.dockerignore`.
- SEO-метаданные репозитория: `pyproject.toml`, `CITATION.cff`, ключевые слова в README.

### Исправлено
- Windows: установлен `WindowsSelectorEventLoopPolicy` — устранены проблемы с SSL и таймаутом семафора.
- Устойчивая загрузка медиа из VK через `urllib` в отдельном потоке (`asyncio.to_thread`).
- Безопасный сброс состояния диалога без `KeyError`.
